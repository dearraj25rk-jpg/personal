Agent SDK Deep Reference

Section titled “Agent SDK Deep Reference”

Subprocess Architecture

Section titled “Subprocess Architecture”

The SDK works by spawning the Claude Code binary as a managed child process. Your application writes prompts to its stdin and reads newline-delimited JSON events from stdout. The binary manages the full agentic loop — tool execution, multi-turn conversation, and cost tracking — internally.

The SDK manages process lifecycle, stream parsing, and reconnection automatically. You only interact with high-level session objects.
