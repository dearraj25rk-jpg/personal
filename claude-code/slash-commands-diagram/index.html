Custom Command Frontmatter Reference

Section titled “Custom Command Frontmatter Reference”

Every custom command file (.claude/commands/<name>.md or ~/.claude/commands/<name>.md) supports the following frontmatter keys:

KeyTypeDefaultDescription
namestringfilenameThe /name used to invoke the command (no spaces)
descriptionstring—One-line description shown in /help and tab completion
allowed-toolslistallTool allowlist scoped to this command only; narrows global permissions
argument-hintlist—Placeholder text shown after the command name in the UI prompt
modelstringsession defaultOverride the model for this command only
contextfork or inheritinheritfork starts a fresh context window; inherit continues the current session
disable-model-invocationbooleanfalseIf true, execute as a pure prompt template — no LLM call, just expand variables

Special Variables Reference

Section titled “Special Variables Reference”
VariableWhat it expands toExample
$ARGUMENTSEverything typed after the command name/commit "feat: add auth" → "feat: add auth"
$1, $2, …Positional arguments split by whitespace/greet Alice Bob → $1 = "Alice", $2 = "Bob"
${CLAUDE_EFFORT}Current effort level settinglow, normal, high, xhigh
${CLAUDE_MODEL}Active model ID for the sessionclaude-sonnet-4-6
@path/to/file.mdInline contents of the file at that pathFile is read and its text is inserted at that point in the prompt
!`shell command`Output of the shell command, captured at invocation time!`git log --oneline -5` → last 5 commit lines
{{placeholder}}Claude is prompted to fill this in before executing{{target environment}} → Claude asks “Which environment?”
