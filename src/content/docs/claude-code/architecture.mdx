## Session Lifecycle — Quick Reference

### Phase 1: Initialization
| Step | What loads | Notes |
|------|-----------|-------|
| Enterprise settings | `~/.claude/managed-settings.json` | Cannot be overridden |
| User settings | `~/.claude/settings.json` | Global preferences |
| Project settings | `.claude/settings.json` | Commit to git |
| Local settings | `.claude/settings.local.json` | Gitignore this |
| Enterprise CLAUDE.md | Managed path | Always-on context |
| User CLAUDE.md | `~/.claude/CLAUDE.md` | Cross-project context |
| Project CLAUDE.md | `CLAUDE.md` (root) | Project context |
| Sub-directory CLAUDE.md | Nested `CLAUDE.md` files | Path-specific context |
| CLAUDE.local.md | `CLAUDE.local.md` | Personal overrides |
| Rules | `.claude/rules/*.md` | Path-scoped |
| MCP servers | `.mcp.json` | Tool extensions |
| Hooks | `settings.json → hooks` | Automation triggers |

### Phase 2: Tool Loop

```
Your prompt
    ↓
Claude API (reads context: CLAUDE.md + Rules + Memory + Skills)
    ↓
stop_reason == "tool_use"?
    ├── YES → Execute tool → check hooks → append result → loop
    └── NO  → Session complete
```

### Phase 3: Compaction
- Triggers at **~85% context used** (auto) or via `/compact`
- Summary replaces conversation history, **MEMORY.md survives**
- Circuit breaker: prevents thrash loops (v2.1.89+)

### Phase 4: Shutdown
- `Stop` hook fires (blockable)
- `PostSessionEnd` hook fires (observe-only)
- Session saved for `/resume` retrieval
