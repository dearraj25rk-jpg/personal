## Native Binary Quick Reference

### Before vs After v2.1.113

```
BEFORE v2.1.113 (Node.js-based)
─────────────────────────────────
  User runs: claude
       │
       ▼
  npx @anthropic-ai/claude-code
       │
       ▼
  Node.js runtime (100–200MB)
       │
       ├── Loads TypeScript compiled JS (~8MB)
       ├── npm registry check on startup
       ├── node_modules/ dependency tree
       └── Glob: child_process spawn of `find`

  Memory baseline: ~180MB
  Requires: Node.js 18+, npm


AFTER v2.1.113 (native binary)
───────────────────────────────
  User runs: claude
       │
       ▼

       │

       ├── No external dependencies
       └── No npm registry calls on startup

  Cold start: 0.8–1.5 seconds  ← 30-50% faster
  Memory baseline: ~45MB       ← 75% smaller footprint
  Requires: nothing (self-contained)
```

### Embedded bfs — File Traversal

`bfs` (Breadth-First Search) replaces the `find` command and the old Glob tool:

| Feature | old `find` | embedded `bfs` |
|---------|-----------|----------------|
| Algorithm | Depth-first | Breadth-first (faster for shallow trees) |
| .gitignore aware | No (manual exclusion needed) | Yes (automatically skips ignored files) |
| .claudeignore aware | No | Yes |
| Symlink handling | Configurable | Follows symlinks up to depth 3 |
| Unicode filenames | Partial | Full Unicode support |
| Performance | Baseline | 1.5–3× faster for typical projects |
| Sorting | Filesystem order | Breadth-first (most relevant files first) |

**Example comparison:**

```bash
# Old behavior (spawned child process)
find . -name "*.ts" -not -path "*/node_modules/*" -not -path "*/.git/*"

# New behavior (embedded bfs, automatically gitignore-aware)
# Glob tool call: pattern="**/*.ts"
# → bfs traversal from cwd, gitignore rules applied automatically
# → results sorted breadth-first (top-level files before deep files)
```

### Embedded ugrep — Content Search

`ugrep` replaces ripgrep (`rg`) for the Grep tool:

| Feature | ripgrep | embedded ugrep |
|---------|---------|----------------|
| Unicode | Partial (UTF-8 only) | Full Unicode (UTF-8, UTF-16, UTF-32) |
| Regex engine | Rust regex | PCRE2 (full Perl-compatible) |
| Multiline patterns | Limited | Full multiline (`-U` flag) |
| Binary file handling | Skip or warn | Configurable per call |
| File type detection | Extension-based | Extension + content sniffing |
| gitignore integration | Yes | Yes |
| Performance | ~1× | ~1.1–1.3× faster for Unicode-heavy files |

**PCRE2 patterns enabled by ugrep:**

```bash
# Lookahead — find async functions that don't have 'await'
# (not possible with basic regex)
pattern: async function (?!.*await)

# Lookbehind — find exports that aren't default exports
pattern: (?<!default )export

# Named capture groups
pattern: (?P<func>async function \w+)

# Multiline matching (spans lines)
pattern: interface \w+ \{[\s\S]*?\}
```

### Installation Methods

#### Method 1: curl (recommended, always latest)

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Installs to `~/.local/bin/claude` on Linux/macOS. Adds to PATH via shell profile.

#### Method 2: npm (for Node.js environments or CI)

```bash
npm install -g @anthropic-ai/claude-code
```

Note: Despite using npm for distribution, v2.1.113+ is a self-contained native binary. npm is only used as the distribution channel, not as a runtime.

#### Method 3: Homebrew (macOS)

```bash
brew install anthropic/tap/claude-code
```

Updates automatically with `brew upgrade`.

#### Method 4: Manual binary download

```bash
# Download for your platform
curl -L "https://github.com/anthropics/claude-code/releases/latest/download/claude-$(uname -s)-$(uname -m)" \
  -o /usr/local/bin/claude
chmod +x /usr/local/bin/claude
```

Platforms available: `darwin-arm64`, `darwin-x64`, `linux-arm64`, `linux-x64`, `windows-x64.exe`

### Enterprise Airgap Deployment

For environments without internet access:

```bash
# STEP 1: Download binary on internet-connected machine
curl -L "https://github.com/anthropics/claude-code/releases/download/v2.1.126/claude-linux-x64" \
  -o claude-v2.1.126-linux-x64

# STEP 2: Verify binary integrity
curl -L "https://github.com/anthropics/claude-code/releases/download/v2.1.126/claude-linux-x64.sha256" \
  -o claude-v2.1.126-linux-x64.sha256
sha256sum -c claude-v2.1.126-linux-x64.sha256

# STEP 3: Sign for internal distribution (optional)
gpg --detach-sign --armor claude-v2.1.126-linux-x64

# STEP 4: Transfer to airgap environment via approved channel
# (USB, internal artifact repo, etc.)

# STEP 5: Deploy to target machines
sudo cp claude-v2.1.126-linux-x64 /usr/local/bin/claude
sudo chmod +x /usr/local/bin/claude

# STEP 6: Pin version to prevent update attempts
export DISABLE_UPDATES=1
# Or add to /etc/environment for all users:
echo "DISABLE_UPDATES=1" >> /etc/environment
```

### DISABLE_UPDATES — Version Pinning

```bash
# Freeze Claude Code at a specific version
export DISABLE_UPDATES=1

# In enterprise managed settings (applies to all users)
# /etc/claude-code/managed-settings.json:
{
  "disableUpdates": true
}

# Verify pinned version
claude --version
# → claude-code v2.1.126 (updates disabled)
```

When `DISABLE_UPDATES=1`:
- Startup update check is skipped (faster startup)
- No prompt to update to newer versions
- Binary version stays fixed until manually updated
- Ideal for: CI/CD pipelines, enterprise managed environments, Docker images

### Binary Integrity Verification

```bash
# SHA-256 checksum verification
sha256sum /usr/local/bin/claude
# Compare with: https://claude.ai/release/v2.1.126/checksums.txt

# GPG signature verification
curl -L https://claude.ai/release/anthropic-signing-key.asc | gpg --import
gpg --verify claude-v2.1.126.sig /usr/local/bin/claude

# macOS Gatekeeper (automatic for curl install)
# Binary is signed with Anthropic Developer ID
codesign -v /usr/local/bin/claude
spctl --assess --type execute /usr/local/bin/claude
```

### Update Mechanism

```
Automatic update flow (when DISABLE_UPDATES is not set):

  Claude Code starts
       │
       ▼
  Check https://claude.ai/releases/latest (async, non-blocking)
       │
       ├── Same version → continue
       │
       └── New version available?
               │
               ▼
         Show update banner at session end:
         "Update available: v2.1.126 → v2.1.127
          Run: claude update  (or auto-installs next session)"
               │
               ▼
         claude update
         → Downloads new binary to temp location
         → Verifies SHA-256 checksum
         → Replaces current binary atomically
         → Exits (restart to use new version)
```
