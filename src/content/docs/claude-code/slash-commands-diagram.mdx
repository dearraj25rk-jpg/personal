## Slash Commands Quick Reference

| Category | Commands |
|----------|---------|

### Custom Command Anatomy

```markdown
<!-- .claude/commands/deploy.md -->
---
description: Deploy the current service to staging
allowed-tools: Bash, Read
---

# Deploy to Staging

## Context
Current branch: !`git branch --show-current`
Service: $ARGUMENTS

## Steps
@import standards/deploy-checklist.md

Run the deployment for the {{service}} service:
...
```

| Variable | Resolves to |
|----------|------------|
| `$ARGUMENTS` | Text typed after the command: `/deploy api-service` → `api-service` |
| `!` prefix | Shell command output: `` !`git log --oneline -5` `` → last 5 commits |
| `@import path` | Contents of another file inserted inline |
| `{{var}}` | Prompt Claude to substitute (not built-in — Claude interprets) |

### Personal vs Project Commands

| Scope | Path | Git? | Visible to |
|-------|------|------|-----------|
| Personal | `~/.claude/commands/<name>.md` | No | Only you, all projects |
| Project | `.claude/commands/<name>.md` | Yes | All team members on this project |
| Plugin | `~/.claude/plugins/<name>/commands/` | Via plugin | Plugin users |

### Invocation

```
> /deploy api-service      ← project command with argument
> /my-standup              ← personal command, no argument
> /deploy<tab>             ← tab completion shows description
```
