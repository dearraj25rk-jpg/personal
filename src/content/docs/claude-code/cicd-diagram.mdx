## CI/CD Quick Reference

### Official GitHub Action

```yaml
# .github/workflows/claude.yml
name: Claude Code Review
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pull-requests: write
    steps:
      - uses: actions/checkout@v4
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          prompt: "Review this PR for bugs, security issues, and style"
          max_turns: "10"
          permission_mode: "default"
```

### Non-Interactive Flags

| Flag | Purpose |
|------|---------|
| `--print` / `-p` | Non-interactive output to stdout |
| `--max-turns N` | Limit agentic loop iterations |
| `--max-budget-usd N` | Hard cost ceiling |
| `--permission-mode` | `default`/`acceptEdits`/`autoAccept`/`bypassPermissions` |
| `--bare` | CI-optimised: 14% faster, skips non-essential steps (v2.1.92+) |
| `--no-color` | Disable ANSI colour codes |
| `--output-format json` | Machine-readable JSON output |

### Cloud Provider Integration

| Provider | Auth method | Variable |
|----------|------------|---------|
| AWS Bedrock | IAM role / OIDC | `CLAUDE_CODE_USE_BEDROCK=1` |
| Bedrock + WIF | OIDC federation | `AWS_WEB_IDENTITY_TOKEN_FILE` |
| Bedrock service tier | Tier selection (v2.1.122+) | `CLAUDE_CODE_BEDROCK_SERVICE_TIER=priority` |
| GCP Vertex AI | Service account / WIF | `CLAUDE_CODE_USE_VERTEX=1` |
| Vertex + WIF | Workload Identity (v2.1.121+) | `GOOGLE_APPLICATION_CREDENTIALS` |

### Security Hardening Checklist

- [ ] Store API keys in CI secrets (never hardcode)
- [ ] Use `bypassPermissions` only in sandboxed CI environment
- [ ] Set `--max-budget-usd` to cap runaway costs
- [ ] Audit hooks log all tool calls
- [ ] Pin `anthropics/claude-code-action@v1` (use SHA pin in production)
- [ ] Restrict `allowedTools` to what CI needs

### Complete GitHub Actions Workflow (Production-Grade)

```yaml
# .github/workflows/claude-review.yml
name: Claude Code Review

on:
  pull_request:
    types: [opened, synchronize, reopened]
  issue_comment:
    types: [created]  # Trigger on /review comment

concurrency:
  group: ${{ github.workflow }}-${{ github.event.pull_request.number }}
  cancel-in-progress: true

jobs:
  claude-pr-review:
    runs-on: ubuntu-latest
    if: github.event_name == 'pull_request' ||
        (github.event_name == 'issue_comment' && contains(github.event.comment.body, '/review'))
    permissions:
      contents: read
      pull-requests: write
      issues: write

    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0  # Full history for accurate diff

      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          model: "claude-sonnet-4-6"
          prompt: |
            Review this pull request. Focus on:
            1. Security vulnerabilities (OWASP Top 10)
            2. Breaking API changes
            3. Missing tests for new code
            4. Performance regressions
            Post findings as inline PR comments with file/line references.
          max_turns: "15"
          max_budget_usd: "3.00"
          permission_mode: "default"
          allowed_tools: "Read,Bash(git*),WebFetch"
          claude_code_flags: "--bare"
```

### Cost Optimisation for CI

| Strategy | Savings | How |
|----------|---------|-----|
| `--bare` flag | ~14% faster | Skips non-essential startup |
| Model selection | 20x cost diff | Haiku for simple checks, Sonnet for review |
| `--max-turns` cap | Prevents runaway | Set N = task complexity × 2 |
| `--max-budget-usd` | Hard ceiling | $0.50 for linting, $3 for full review |
| Prompt caching | 75% off cached tokens | Same CLAUDE.md + CI = 90%+ hit rate |
| `--allowed-tools` restriction | Scope reduction | Only give CI the tools it needs |

## CI/CD Deep Reference

### Full Pipeline Flow

```
Git push / PR event / manual trigger
    │
    ▼
GitHub Actions / GitLab CI / Azure DevOps trigger
    │
    ▼
actions/checkout@v4  +  anthropics/claude-code-action@v1
    │
    ├── Auth: ANTHROPIC_API_KEY  ──────────────────────┐
    ├── Auth: AWS Bedrock IAM role / OIDC               │
    └── Auth: GCP Vertex AI Workload Identity (WIF)     │
                                                         │
    ▼                                                    │
claude --print "task"                                    │
      --permission-mode bypassPermissions                │
      --bare                                             │
      --max-turns N                                      │
      --max-budget-usd N ◄──────────────────────────────┘
    │
    ├── Tool: Read (repo files, diffs)
    ├── Tool: Bash(git *) (log, diff, blame)
    └── Tool: WebFetch (issue tracker, docs)
    │
    ▼
Agentic loop (up to --max-turns iterations)
    │
    ▼
Results
    ├── PR comment (via GitHub API)
    ├── Commit to branch (via git push)
    ├── Artifact upload (review.json, report.md)
    └── Exit code 0 (success) / non-zero (failure → fail CI job)
```

### Complete GitHub Actions Workflow — All Triggers

```yaml
# .github/workflows/claude-full.yml
# Covers: PR review, comment responder, scheduled audit, manual dispatch
name: Claude Code CI

on:
  pull_request:
    types: [opened, synchronize, reopened]
  issue_comment:
    types: [created]
  schedule:
    - cron: "0 2 * * 1"   # Weekly security audit — Mondays 02:00 UTC
  workflow_dispatch:
    inputs:
      task:
        description: "Task for Claude to run"
        required: true
        default: "Audit the codebase for security issues"

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  # ── Job 1: PR Review ─────────────────────────────────────────────
  pr-review:
    if: github.event_name == 'pull_request'
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pull-requests: write
      issues: write

    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          model: "claude-sonnet-4-6"
          prompt: |
            Review this pull request for:
            1. Security vulnerabilities (OWASP Top 10)
            2. Breaking API changes
            3. Missing tests for new logic
            4. Performance regressions
            Post findings as inline PR comments referencing file + line.
          max_turns: "15"
          max_budget_usd: "3.00"
          permission_mode: "default"
          allowed_tools: "Read,Bash(git*)"
          claude_code_flags: "--bare"

  # ── Job 2: Comment Responder (/review, /fix, /explain) ───────────
  comment-responder:
    if: |
      github.event_name == 'issue_comment' &&
      (contains(github.event.comment.body, '/review') ||
       contains(github.event.comment.body, '/fix') ||
       contains(github.event.comment.body, '/explain'))
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write

    steps:
      - uses: actions/checkout@v4
        with:
          ref: ${{ github.event.issue.pull_request.head.ref }}
          fetch-depth: 0

      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          model: "claude-sonnet-4-6"
          prompt: |
            A team member posted: "${{ github.event.comment.body }}"
            Carry out that request on this PR. If it asks for /fix,
            make the code changes and commit them. If /review or /explain,
            post a comment with findings.
          max_turns: "20"
          max_budget_usd: "5.00"
          permission_mode: "acceptEdits"
          allowed_tools: "Read,Edit,Write,Bash(git*)"

  # ── Job 3: Scheduled Weekly Audit ────────────────────────────────
  weekly-audit:
    if: github.event_name == 'schedule'
    runs-on: ubuntu-latest
    permissions:
      contents: read
      issues: write

    steps:
      - uses: actions/checkout@v4

      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          model: "claude-opus-4-6"
          prompt: |
            Perform a weekly security and dependency audit:
            1. Check for known CVEs in package.json / requirements.txt
            2. Find any hardcoded secrets or credentials
            3. Identify deprecated API usage
            4. Report findings as a GitHub issue titled "Weekly Audit YYYY-MM-DD"
          max_turns: "25"
          max_budget_usd: "10.00"
          permission_mode: "default"
          allowed_tools: "Read,Bash(npm audit),Bash(grep*),WebFetch"
          claude_code_flags: "--bare"

  # ── Job 4: Manual Dispatch ────────────────────────────────────────
  manual-task:
    if: github.event_name == 'workflow_dispatch'
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write

    steps:
      - uses: actions/checkout@v4

      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          model: "claude-sonnet-4-6"
          prompt: ${{ github.event.inputs.task }}
          max_turns: "30"
          max_budget_usd: "15.00"
          permission_mode: "bypassPermissions"
          allowed_tools: "Read,Edit,Write,Bash(git*),Bash(npm*)"
```

### AWS Bedrock — Service Tiers and IAM Configuration

AWS Bedrock offers three service tiers for Claude in CI (v2.1.122+). Select the tier matching your CI workload's latency and throughput requirements.

| Tier | Variable value | Use case | Characteristics |
|------|---------------|----------|-----------------|
| Default | `default` (or unset) | Production review jobs | Standard throughput, balanced cost |
| Flex | `flex` | Async batch CI, audit jobs | Lower cost, higher latency acceptable |
| Priority | `priority` | Blocking PR checks | Highest throughput, premium cost |

### GCP Vertex AI — Workload Identity Federation (v2.1.121+)

WIF lets GitHub Actions authenticate to GCP without storing a service account key. The GitHub Actions OIDC token is exchanged for a short-lived GCP access token.

**Setup (one-time, via gcloud):**

```bash
# 1. Create Workload Identity Pool
gcloud iam workload-identity-pools create "github-actions" \
  --project="YOUR_PROJECT_ID" \
  --location="global" \
  --display-name="GitHub Actions Pool"

# 2. Create OIDC Provider
gcloud iam workload-identity-pools providers create-oidc "github" \
  --project="YOUR_PROJECT_ID" \
  --location="global" \
  --workload-identity-pool="github-actions" \
  --display-name="GitHub OIDC Provider" \
  --issuer-uri="https://token.actions.githubusercontent.com" \
  --attribute-mapping="google.subject=assertion.sub,attribute.repository=assertion.repository" \
  --attribute-condition="assertion.repository=='YOUR_ORG/YOUR_REPO'"

# 3. Bind service account
gcloud iam service-accounts add-iam-policy-binding \
  "claude-code-ci@YOUR_PROJECT_ID.iam.gserviceaccount.com" \
  --project="YOUR_PROJECT_ID" \
  --role="roles/iam.workloadIdentityUser" \
  --member="principalSet://iam.googleapis.com/projects/PROJECT_NUMBER/locations/global/workloadIdentityPools/github-actions/attribute.repository/YOUR_ORG/YOUR_REPO"
```

**Service account IAM roles required:**

| Role | Purpose |
|------|---------|
| `roles/aiplatform.user` | Invoke Vertex AI models |
| `roles/ml.admin` | (Optional) Model endpoint management |

### Security Hardening Checklist

| Check | Why it matters | How to implement |
|-------|---------------|-----------------|
| Pin actions to commit SHA | Prevents supply-chain attacks from tag mutation | `uses: actions/checkout@a5ac7e51b41094c92402da3b24376905139b6c84` instead of `@v4` |
| Use OIDC instead of long-lived secrets | Eliminates key rotation risk; tokens expire in minutes | GitHub → AWS: `aws-actions/configure-aws-credentials` with `role-to-assume`; GCP: WIF provider |
| Set `--max-budget-usd` | Prevents runaway cost if prompt loops | `max_budget_usd: "3.00"` — match to task complexity |
| Use `--bare` mode | Skips non-essential steps; reduces attack surface | `claude_code_flags: "--bare"` |
| Restrict to `bypassPermissions` only for trusted repos | Untrusted forks should not auto-accept file writes | Add `if: github.event.pull_request.head.repo.full_name == github.repository` |
| Scope `allowed_tools` | Principle of least privilege | PR review needs only `Read,Bash(git*)` — never grant `Write` for review-only jobs |
| Rotate API keys quarterly | Limits blast radius of leaked keys | Use GitHub secret rotation; prefer OIDC to eliminate keys entirely |
| Enable concurrency controls | Prevents parallel CI runs from double-posting | `concurrency: group: ${{ github.workflow }}-${{ github.ref }}` |
| Audit tool call logs | Detect unexpected tool use in CI | Enable `PostBash` hook to log all shell commands |
| Sandbox CI runners | Prevent lateral movement if compromised | Use ephemeral `ubuntu-latest` runners; avoid self-hosted for untrusted code |

```yaml
# Minimal secure template — copy as starting point
```

### Cost Optimisation for CI

**Model selection by task type:**

| Task | Recommended model | Approx cost per run | Notes |
|------|-----------------|--------------------|----|
| Lint / format check | `claude-haiku-4-5` | $0.01–0.05 | Simple pattern matching |
| Unit test generation | `claude-haiku-4-5` | $0.05–0.20 | Template-heavy |
| PR security review | `claude-sonnet-4-6` | $0.50–2.00 | Default choice |
| Full architecture review | `claude-opus-4-6` | $5.00–15.00 | Complex reasoning needed |
| Scheduled audit | `claude-sonnet-4-6` | $2.00–8.00 | Balance quality and cost |

**Set model via environment variable:**

```yaml
env:
  CLAUDE_CODE_MODEL: "claude-haiku-4-5"   # Override for lint/format jobs
```

**Bedrock flex tier for async CI (lower cost, higher latency):**

```yaml
env:
  CLAUDE_CODE_USE_BEDROCK: "1"
  CLAUDE_CODE_BEDROCK_SERVICE_TIER: "flex"   # 30-40% cheaper vs default tier
```

**Prompt cache warming (75% off cached tokens):**

```yaml
# Include CLAUDE.md in first turn — same content = cache hit on repeat runs
- uses: anthropics/claude-code-action@v1
```

**Full cost optimisation matrix:**

| Strategy | Typical saving | Trade-off |
|----------|--------------|-----------|
| Haiku for lint/format tasks | 20× cost reduction | Lower quality on complex tasks |
| `--bare` flag | ~14% faster / cheaper | Minor: skips some startup steps |
| `--max-turns N` cap | Prevents runaway loops | May not complete very complex tasks |
| `--max-budget-usd` hard cap | Hard ceiling | Job fails if budget exceeded |
| Prompt cache warm (CLAUDE.md) | 75% off cached tokens | Only effective for repeated prompts |
| Bedrock flex tier | 30–40% vs default | Higher latency (batch-suitable only) |
| `--allowed-tools` restriction | Avoids unnecessary tool calls | Must list all required tools |
