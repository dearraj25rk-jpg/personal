**RAG Academy** is a structured, interactive course covering every layer of a production RAG system. Each module builds on the last, taking you from a single-file prototype to a hybrid, reranked, evaluated pipeline.

## Course Modules

| Module | Topics covered |
|---|---|
| **1 — Foundations** | What RAG is, why it reduces hallucinations, when to use it |
| **2 — Chunking** | Fixed-size, recursive, semantic, late chunking, agentic chunking |
| **3 — Embeddings** | Bi-encoder vs cross-encoder, MTEB benchmarks, model selection |
| **4 — Vector Search** | HNSW, IVF, flat index, ANN algorithms, distance metrics |
| **5 — Hybrid Search** | BM25 + dense, RRF fusion, when to use each component |
| **6 — Reranking** | Cross-encoder reranking, FlashRank, Cohere Rerank, ColBERT |
| **7 — Generation** | Prompt assembly, citation formatting, context window management |
| **8 — Evaluation** | RAGAS metrics, faithfulness, answer relevancy, context precision |
| **9 — Production** | Semantic caching, observability, guardrails, cost optimization |

## How to Use This Course

The course is fully self-contained — each module includes:
- A concept explanation with visual examples
- Live code you can inspect and modify
- A mini-quiz to check understanding before advancing

## The Complete RAG Stack

```
┌──────────────────────────────────────────────────────────────────┐
│                        RAG SYSTEM                                │
│                                                                  │
│  INDEXING PIPELINE (offline)                                     │
│  ─────────────────────────────────────────────                   │
│  Documents → Chunking → Embedding → Vector Store                 │
│                                          ↓                       │
│                                    HNSW Index                    │
│                                    + BM25 Index                  │
│                                                                  │
│  QUERY PIPELINE (online, per request)                            │
│  ─────────────────────────────────────────────                   │
│  User Query → Embed Query → Hybrid Search (dense + BM25)         │
│                                    ↓                             │
│                              RRF Fusion                          │
│                                    ↓                             │
│                           Cross-encoder Reranking                │
│                                    ↓                             │
│                              Top-N Chunks                        │
│                                    ↓                             │
│                           Prompt Assembly                        │
│                                    ↓                             │
│                            LLM Generation                        │
│                                    ↓                             │
│                         Answer + Citations                       │
└──────────────────────────────────────────────────────────────────┘
```
